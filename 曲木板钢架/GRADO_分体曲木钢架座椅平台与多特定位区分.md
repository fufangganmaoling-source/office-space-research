# GRADO 分体曲木钢架座椅平台与多特定位区分

## 一、核心判断

如果“能够持续衍生产品、支撑项目业务、扩大品牌覆盖面”是开发分体曲木钢架座椅平台的唯一理由，那么该项目不具备充分的立项必要性，因为多特、爱沃等现有产品已经具备多配置、多场景和项目化应用能力。

新平台成立的前提，不是再次建立一个“什么空间都能用”的基础产品，而是补足现有塑料座椅平台无法自然覆盖的材料质感、空间气质和品牌设计表达。

## 二、多特与分体曲木钢架平台的定位差异

| 对比维度 | 多特平台 | 分体曲木钢架平台 |
| --- | --- | --- |
| 平台属性 | 功能效率型平台 | 材料与设计型平台 |
| 核心任务 | 提升空间配置、移动与变化效率 | 提升空间质感、材料协调与品牌识别 |
| 核心材料 | PP+玻璃纤维、钢架 | 分体曲木座背、钢架 |
| 核心优势 | 轻巧、耐用、可堆叠、可配置桌板 | 温暖、克制、有家具感、易融入室内材料体系 |
| 首要场景 | 培训、教育、会议及多功能空间 | 餐饮、会客、洽谈、阅读、固定会议及设计型公共空间 |
| 客户购买理由 | 好用、灵活、容易布置 | 有质感、有设计识别度、符合空间材料语言 |
| 衍生逻辑 | 围绕扶手、桌板、软包等功能配置扩展 | 围绕座板、靠背、脚架、饰面及结构接口扩展 |
| 品牌角色 | 高效率的项目工具 | 可规模化的品牌设计载体 |

## 三、为什么多特不能完全替代曲木钢架平台

多特的核心价值来自轻薄PP座背、堆叠能力、桌板配置和高频公共空间适应性。即使能够进入餐区、洽谈区和休闲区，其主要竞争优势仍然是培训及灵活空间中的功能效率。

分体曲木钢架平台需要解决的是另一类需求：客户希望使用更温暖、更有家具感的材料，同时仍然需要项目化价格、稳定交付和系列化配置。

曲木材料能够带来：

- 更自然的视觉和触觉温度；
- 更强的家具感与长期陈设感；
- 与木饰面、建筑材料和室内空间更好的协调性；
- 区别于塑料座椅的品牌识别与价值感知。

因此，两者不应形成新旧替代关系，而应分别承担不同的产品任务：

- **多特负责动态空间的使用效率；**
- **分体曲木钢架负责固定空间的材料质感。**

## 四、与品牌其他基础多配置产品的区分

GRADO现有基础多配置产品已经可以通过不同脚架、软包、扶手、桌板和高度覆盖多个场景。新平台不能再以“配置更多”或“适用空间更广”作为主要价值，否则会造成产品重叠、内部竞争以及模具和库存复杂度增加。

分体曲木钢架平台应建立三个明确边界：

1. **不以培训场景为核心**  
   主要面向餐饮、会客、洽谈、阅读、固定会议及设计型公共空间。

2. **不以配置数量作为核心竞争力**  
   核心价值是曲木与钢架形成的材料语言、家具感和品牌识别。

3. **不只是更换材质的现有产品**  
   必须建立座板、靠背、脚架和连接结构之间可复用的独立接口，形成新的底层产品架构。

## 五、项目成立的必要条件

在正式投入开发前，需要确认：

- 过往项目中确实存在无法由多特、爱沃等现有产品满足的木质材料需求；
- 新产品的核心订单来自非培训场景，而不是与多特争夺同一项目；
- 客户愿意为材料质感和设计识别支付相应价格；
- 共用接口能够支持后续产品扩展，并真正减少重复开发；
- 新平台能够形成清晰、独立且可被销售团队准确表达的购买理由。

如果以上条件不能成立，则不建议开发；如果能够成立，该平台将成为GRADO在功能效率型塑料座椅之外的第二类基础产品系统。

## 六、结论

GRADO开发分体曲木钢架座椅平台，不是因为品牌缺少多配置产品，而是因为现有平台主要解决功能效率与多场景适应问题，品牌仍缺少一个以天然材料、空间质感和设计识别为核心，同时具备项目化价格与批量交付能力的基础座椅平台。

## 一句话定位

> **分体曲木钢架座椅平台，是GRADO区别于多特及其他以功能配置和场景覆盖为核心的基础产品，以曲木材料、结构表达和空间质感为核心价值，面向固定型设计项目的温暖材料基础座椅系统。**
