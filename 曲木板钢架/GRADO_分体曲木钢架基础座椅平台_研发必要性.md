# GRADO 分体曲木钢架基础座椅平台研发必要性

## 一、核心判断

GRADO 研发“分体曲木钢架基础座椅平台”，不是为了增加一把新椅子，而是为了建立一个能够持续衍生产品、支撑项目业务、扩大品牌覆盖面的基础产品系统。

这款产品应被视为 GRADO 未来基础座椅品类的“底盘”：以一套经过验证的座背、脚架和连接接口为基础，逐步发展不同配置与使用场景，推动品牌从单品开发走向平台化开发。

## 二、品牌为什么需要研发这一方向

### 1. 补齐品牌的基础产品结构

GRADO 的高调性产品负责建立品牌高度，但品牌同时需要一款价格合理、需求广泛、能够稳定销售的基础产品。

分体曲木钢架座椅可以承担以下角色：

- P 线的基础配置产品；
- 项目渠道的标准化产品；
- 经销与零售渠道的入门产品；
- 带动桌类、软体及其他高调性产品成交的组合产品。

它不一定是品牌中最抢眼的产品，却可能成为覆盖客户最多、使用周期最长、出货最稳定的产品。

### 2. 从开发单品升级为建设产品平台

分体曲木与钢架结构具备天然的模块化条件，可以将产品拆分为：

- 曲木座板与靠背；
- 钢制脚架；
- 标准连接结构；
- 木饰面与金属颜色；
- 后续软包、扶手及不同脚架配置。

建立统一接口后，GRADO 可以在同一基础平台上持续发展系列产品，由此实现：

- 缩短后续产品的开发周期；
- 摊薄模具及工程投入；
- 提高零部件复用率；
- 降低备料和库存复杂度；
- 提升项目配置与快速响应能力。

因此，本项目的成果不应只是一款产品，而应是一套可以反复使用的产品架构。

### 3. 建立项目业务的标准化成交工具

项目客户不仅关注造型，也重视价格、交期、批量品质、空间适配、后期补货和维护便利性。

按照现有开发计划，该产品首发价格带为 1,400–1,800 元，具有进入办公、餐饮、教育、公共空间、会客及复合商业空间的潜力。

这将帮助 GRADO 从“提供有设计感的单品”进一步转向“提供能够规模化配置的产品”，使其成为项目报价、空间配置与组合销售中的基础产品。

### 4. 沉淀可持续的品牌设计语言

曲木与钢架具有明确的材料互补关系：

- 曲木提供温度、触感与家具感；
- 钢架提供轻盈、秩序、效率与现代感；
- 分体结构使比例、留缝和连接节点成为可识别的设计细节。

如果持续统一比例、结构节点和 CMF 逻辑，该平台可以形成属于 GRADO 的产品语言：**克制、现代、具有结构感，但不冰冷。**

未来即使调整脚架、座背轮廓、颜色或软包配置，消费者仍能感知这些产品属于同一个品牌家族。

### 5. 建立难以被复制的产品与供应链能力

本项目能够帮助团队沉淀以下长期能力：

- 曲木座背的人体工学和回弹控制；
- 木件与钢架的标准连接方式；
- 批量生产的公差和装配控制；
- 脚架、座背与软包之间的接口规则；
- CMF 与产品家族化管理；
- 成本、包装、运输及售后零件体系。

竞争对手可以模仿一款产品的外形，但更难复制一套成熟的接口、工程标准、成本控制和系列衍生能力。这些能力将成为 GRADO 可以持续复用的技术资产与供应链资产。

### 6. 平衡品牌高度与经营规模

GRADO 的产品结构需要形成双重驱动：

| 产品角色 | 核心任务 |
| --- | --- |
| 高调性产品 | 建立审美高度、话题性与品牌溢价 |
| 基础座椅平台 | 建立销量、渠道覆盖、项目适配与稳定复购 |

只有高调性产品，品牌可能有形象但缺少规模；只有基础产品，品牌可能有销量但缺少高度。

分体曲木钢架基础座椅平台的价值，在于它能够连接这两者：既保留 GRADO 应有的设计品质，又进入更广泛、更高频的真实使用场景。

## 三、项目的战略定位

该方向不应被定义为“开发一款基础四脚椅”，而应被定义为：

> 建立 GRADO 首个可持续扩展的基础座椅平台，以统一接口、稳定结构和品牌化设计语言，支撑项目业务、渠道销售及后续系列化开发。

首款固定四脚椅是平台的验证载体，重点需要验证：

1. 座背与脚架的共用接口是否可靠；
2. 人体工学与结构强度是否适合批量应用；
3. 目标价格带能否保持合理利润；
4. 产品是否具备明确的 GRADO 识别度；
5. 后续配置是否能够在不重做底层结构的情况下快速扩展。

## 四、决策层应关注的四个问题

1. 我们能否用一套核心结构，持续发展出一个完整系列？
2. 我们能否在 1,400–1,800 元价格带仍然保持 GRADO 的设计辨识度？
3. 它能否成为项目渠道愿意长期使用和重复采购的标准产品？
4. 本次投入能否沉淀为下一批产品可复用的接口、模具和供应链能力？

如果答案是肯定的，那么项目回报就不应只用首款椅子的销量衡量，而应评估整个平台未来 3–5 年的累计贡献。

## 五、立项结论

GRADO 需要研发分体曲木钢架基础座椅平台，因为品牌下一阶段不仅需要更多具有调性的产品，也需要建立能够支撑规模化经营的基础产品能力。

该方向能够补齐 P 线基础价格带，提升项目渠道适配能力，形成可延展的产品家族，并将本次研发投入转化为可复用的结构、模具、供应链和品牌设计资产。

**因此，我们研发的不是一把基础椅，而是 GRADO 未来基础座椅品类的底盘。它将推动品牌从单品开发走向平台化开发，从依靠设计亮点走向兼具品牌高度与经营规模的长期产品体系。**
