# 办公空间调研

本仓库用于持续开展办公空间案例研究，从真实项目中提炼空间需求、家具趋势、家具组合方法和产品开发机会。

研究资料按以下流程管理：

```text
项目调研 → Markdown 报告 → GitHub 审核 → Obsidian 归档
             └→ 项目图片单独归入 Eagle
```

## 当前调研

新一轮调研按照月度计划执行。每日研究报告通过独立分支和 Pull Request 提交，审核通过后再归入主分支与 Obsidian。

## 调研方法与 SOP

- [查看办公空间调研全流程 SOP](./办公空间调研全流程_SOP.md)
- [查看行业五次调研汇总 SOP](./办公空间行业五次调研汇总_SOP.md)：同一行业累计 5 份已审核日报后，另出一份行业汇总并单独提交审核。

## 固定报告结构

1. 案例采集
2. 空间类型出现频率
3. 空间设计趋势
4. 家具设计趋势
5. 软装家具搭配方法
6. 产品开发启发
7. 测试结论与研究限制

其中“软装家具搭配”只讨论家具与家具之间的组合，不扩展到灯具、地毯、窗帘、绿植或艺术品。

## 资料归档

- **GitHub**：保存调研报告、流程文件和版本历史。
- **Eagle**：保存项目参考图片及来源标签。
- **Obsidian**：保存用户审核通过的最终 Markdown 文档。
