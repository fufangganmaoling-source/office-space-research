# 办公空间调研

本仓库用于持续开展办公空间案例研究，从真实项目中提炼空间需求、家具趋势、家具组合方法和产品开发机会。

研究资料按以下流程管理：

```text
项目调研 → Markdown 报告 → GitHub 审核 → Obsidian 归档
             └→ 项目图片单独归入 Eagle
```

## 当前调研

### 2026-10-02｜建筑与设计公司办公空间

- 样本数量：10 个项目
- 主要来源：Office Snapshots
- 研究内容：空间类型频率、空间趋势、家具设计趋势、家具搭配方法和产品开发启发
- [查看调研报告](./2026-10-02_Architecture_Design_Firms_Office_Research_v2.md)

## 固定报告结构

1. 案例采集
2. 空间类型出现频率
3. 空间设计趋势
4. 家具设计趋势
5. 软装家具搭配方法
6. 产品开发启发
7. 测试结论与研究限制

其中“软装家具搭配”只讨论家具与家具之间的组合，不扩展到灯具、地毯、窗帘、绿植或艺术品。
